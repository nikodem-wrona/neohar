# Code of conduct

neohar uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all spaces of the project: issues, pull requests, discussions, reviews and commit messages.

## Report a problem

Use **Report content** on GitHub to report behavior that the code of conduct does not permit. This item is in the `...` menu of each comment, issue and pull request. Send the report to the maintainers of the repository when GitHub gives that choice. Else, GitHub Support gets the report.

The maintainer reviews each report and keeps the name of the reporter private.
